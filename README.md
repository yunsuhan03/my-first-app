# 🎓 Hello, SKKU

A dynamic and interactive **Streamlit dashboard** built for SKKU (Sungkyunkwan University). This project visualizes and presents university-related data and information through a clean, user-friendly web interface.

---

## 📖 Description

**Hello, SKKU** is a Streamlit-based web dashboard designed to make university data accessible and engaging. Whether you're exploring academic insights, campus information, or statistical overviews, this app delivers it all in one place — no installation headaches, just run and explore.

---

## ✨ Features

- 📊 **Interactive Dashboard** — Real-time data visualizations powered by Streamlit
- 🖥️ **Clean UI** — Simple and intuitive interface for all users
- 📁 **Data Integration** — Easily connects to local or remote data sources
- ⚡ **Fast & Lightweight** — Runs instantly in your browser
- 🔧 **Customizable** — Modular structure makes it easy to extend

---

## 🚀 How to Run

### 1. Clone the repository

```bash
git clone https://github.com/your-username/hello-skku.git
cd hello-skku
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Run the Streamlit app

```bash
streamlit run app.py
```

### 4. Open in your browser

The app will automatically open at:
```
http://localhost:8501
```
